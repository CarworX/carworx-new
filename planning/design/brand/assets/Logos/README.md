# Logos

The locked Turbine logo (D-034). See the [brand README](../../README.md) for usage.

- **`carworx-turbine-mark.svg`:** the symbol alone, transparent background, single colour `ink` #0d0f12.
- **`carworx-turbine-lockup.svg`:** mark and wordmark on `ink`, 1200 × 630.
- **`carworx-turbine-animated.svg`:** the lockup with motion; the Claude Design asset store strips animation from SVGs, so it is kept here as a file.
