# PageLoader

The main loading screen between pages: the dot-grid ripple.

- The Turbine rotor sits in the middle of the canvas grid and indexes one blade (72°) every 1.2 s, like a ratchet, with the brand's 1.8° overshoot. Each index sends a pressure wave, with a smaller echo, across the grid: dots swell, turn `blue` and push outward.
- The blades rest pale (`ink` at 14 %). On one index, solid `ink` runs from the hub out to the tips and stays; on the next it runs back to the hub. Out, back, out, back.
- Use it for page-to-page waits only. In a page, use the hold dial or a skeleton (see Loaders).
- Reduced motion: one frozen wave and the rotor at rest as the solid black logo.
- Only the fill changes: the blade path and rest angles are the logo's own.
