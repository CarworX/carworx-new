# PhoneFrame

The frosted phone shell used to present mobile screens: a 10px frosted bezel (radius-phone), a 34px-radius screen, a mono status bar, an app bar, the body and a floating pill tab bar.

- Screens are designed at **360px** wide first. Body copy 13.5 to 15px; nothing under 12px.
- The tab bar floats 12px above the bottom: Home, Search, Bookings, Account (business: Today, Calendar, Quotes, Business).
- Concepts carry "Concept, not final" in the status bar.
- This is a presentation frame. In the product the screen content is the app; the shell is not shipped.
