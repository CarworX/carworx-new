# Loaders

Which loader to use for which kind of wait. There are three, and each has one job.

| Where | Loader |
|---|---|
| In a button | Hold dial's plain spinning arc (`blue`; white on the ink pill). The label says what is happening and the button keeps its size. |
| In a page, a multi-step wait the user is watching (search, availability, quotes) | Hold dial: the ring fills one honest step at a time, with a rolling status line (a polite live region). `blue`, never `signal`: loading is not a countdown. |
| In a page, when the layout is known (results, a listing, the dashboard) | Skeleton cards with one soft shimmer that crosses the page. |
| On a card or in a list | A skeleton row for the one item still loading. |
| Between pages | The dot-grid ripple (PageLoader). |

Rotor spool and the standalone blade index are retired as loaders (D-041). The brand's one-blade 72° index lives on as the ripple rotor's rhythm.
