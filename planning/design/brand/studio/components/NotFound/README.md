# NotFound

The CarworX 404 page: the Studio dot grid set as "404", with the Turbine rotor as the 0 and a glass loupe that follows the pointer.

- Copy, always: eyebrow "Error 404 · page not found", headline "We can't find that page." with the grey line "It may have moved.", then "Check the address for a typo, or start again from home."
- Actions: the ink pill **Back to home** and the text link **Find a service**, then "Or go straight to" and the five service chips in brief order and full wording.
- Motion: the loupe follows on a spring; dots under it swell and turn `blue`; a click or tap sends a pressure wave; the rotor 0 indexes 72° every 3.2 s, mechanically. Idle, the loupe drifts along the numerals.
- Phones: the same page full screen (see NotFoundPhone); chips drop their objects and wrap.
- Reduced motion: the loupe rests over the rotor and nothing moves.
- Canvas 2D, about 5,000 dots on springs; it stays inside 16 ms a frame at the 95th percentile in headless checks. Not yet profiled on a real phone.
- Source: `planning/design/states/` (D-041).
