# StatusNote

A sentence-first note that says what happened and what happens next.

- Default (white, info icon in blue-ink): neutral facts and honest limits ("CarworX is new…").
- `.warn`: waiting, expiring, lapsed. `.err`: failed or paused. `.ok`: done.
- Start with a bold sentence of what happened, then what it means for the person ("Nothing was taken", "Your slot is still held for 09:12").
- Always an icon **and** words; never colour alone.

**Tone:** plain, honest, calm South African English. Say: "Request sent. Gleamline has until 11:40 to reply. You haven't paid anything." Not: "Booked instantly!"
