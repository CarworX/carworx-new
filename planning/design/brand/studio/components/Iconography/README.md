# Iconography

One sheet of every Studio picture on its real ground: the five soft-3D service objects, the ten hand-drawn state illustrations and the 25 line glyphs.

- **Service objects** appear only on the five shortcuts (key-caps on desktop, key rows on phones) and their service pages. Never as general icons.
- **Illustrations** sit beside a sentence that says the same thing, at 96 to 120 px wide, with `alt=""`.
- **Glyphs** go in code as CSS masks so they take `currentColor`: `<span class="cx-ic search"></span>`, at 16, 20 or 24 px. Pair each with a word, or give a universally understood control an `aria-label`.
- The files are drawn in `ink` (#0d0f12). On a dark page, such as the Assets list in dark mode, they are hard to see: check them here, on `canvas`.
