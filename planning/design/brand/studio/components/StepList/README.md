# StepList

Numbered steps of a journey, each with who acts (`cx-actor`), what they do, and what it means.

- The numbers are real order: use this only for sequences.
- The active step (`.on`) lifts to white with sh-2. In the pack the active step follows scroll and drives the booking object (sticky note → tile → dial → receipt). That link is scroll-linked, never scroll-jacked, and the list reads fully as a still and in print.
