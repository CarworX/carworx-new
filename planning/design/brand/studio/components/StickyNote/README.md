# StickyNote

The driver's own intention before it becomes a request: a note in Caveat on note-yellow, taped, slightly rotated.

- Decorative and explanatory only (marketing, journeys, empty states). **Never** an input or anything a person must act on.
- Two lines: the job in `note` (24px, 600), a reminder at 19px in a darker tone. Keep it under eight words.
- In the booking journey it is stage 1, followed by BookingTile, HoldDial and ReceiptQuote.
