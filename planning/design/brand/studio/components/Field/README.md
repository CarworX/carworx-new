# Field

Inputs on white with a 1.5px `control-edge` outline (3.2:1), radius-sm, 44px minimum.

- `cx-search` is the big search bar on canvas (no outline, sh-1).
- `cx-input` inside `cx-field` with a visible label above it. Never rely on placeholder text as the label.
- `cx-seg` is a two- or three-way choice (List/Map; premises/mobile). Use radio semantics.
- `cx-check` with `cx-box` for consent and opt-ins; say exactly what the data is used for.

**Privacy copy is part of the field:** "Your base (kept private)", "Used only for this". Never ask for an ID number.
