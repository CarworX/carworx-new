# EmptyState

One hand-drawn line illustration (asset group *Illustrations*), one sentence of what is true, and one way forward.

- Illustrations: `few` (limited supply), `nothing` (nothing nearby), `error` (didn't load), `expired` (hold or quote ran out), `card` (payment failed), `paused` (business paused), `noreply` (no reply in time), `review` (under review, problem reported), `leave` (leaving CarworX), `sent` (request sent).
- Illustrations are decorative: `alt=""`. The heading carries the meaning.
- Never say "no fines" because a search found nothing; never widen a search silently.
